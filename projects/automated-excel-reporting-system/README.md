# Automated Excel Reporting System

CSV/XLSX in → profile, missing values, numeric summaries, and a formatted multi-sheet report.

## Aim
Provide a dependable, repeatable workflow for automated excel reporting system.

## Objectives
- Reduce repetitive manual work
- Provide predictable outputs and clear error handling
- Include sample usage and automated tests
- Offer Lite and Production editions

## Editions
- **Lite:** focused local CLI / starter implementation with minimal setup
- **Production:** same core workflow with container, CI, logging/config scaffolding
