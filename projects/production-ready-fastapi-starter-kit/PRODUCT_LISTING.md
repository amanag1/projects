# Gumroad product listing

## Product name
Production-Ready FastAPI Starter Kit

## Short summary
Build a cleaner Python API foundation with a minimal FastAPI Lite edition and a modular, container-ready Production edition.

## Description
Skip repetitive project setup and start with a practical structure you can understand and extend. This kit includes two distinct editions for different stages of development.

### Lite edition
- Small FastAPI application with clear route separation
- Environment-based configuration
- Request validation and consistent error responses
- Health endpoint and pytest tests
- Minimal dependencies and quick local setup

### Production edition
- Modular API, core, service, database and UI boundaries
- Pydantic settings and structured logging
- Request ID middleware and health/readiness endpoints
- Dockerfile and Docker Compose
- GitHub Actions CI, Helm starter chart and operational docs
- Example tests and local development scripts

### Included
Complete source code for both editions, setup instructions, architecture notes, sample environment configuration and Gumroad-ready product assets.

**Scope note:** Authentication, a database vendor, migrations, distributed tracing, rate limiting and cloud-specific deployment policies are intentionally left as integration choices rather than represented as already implemented.
