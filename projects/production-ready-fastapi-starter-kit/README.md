# Production-Ready FastAPI Starter Kit

A structured FastAPI foundation for building maintainable Python APIs. Includes a lightweight edition for learning and small services, plus a modular production-oriented edition with settings, logging, request IDs, health endpoints, validation, tests, container assets and a Helm starter chart.

## Editions
- [Lite](production-ready-fastapi-starter-kit-lite/README.md): minimal dependencies and a compact API.
- [Production](production-ready-fastapi-starter-kit-production/README.md): modular application layout and deployment scaffolding.

## Intended audience
Python developers who want a clean starting point for REST APIs without introducing unnecessary infrastructure.

## Important
The Production edition is a starter template, not a fully secured turnkey platform. Add authentication/authorization, secrets management, rate limiting, tracing, persistence and deployment-specific policies as required by your application.
